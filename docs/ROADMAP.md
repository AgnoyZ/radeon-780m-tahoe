# 研发路线与验收

所有研发阶段均为待完成；仓库建立不等于驱动已经实现。

| 阶段 | 工作 | 验收条件 |
| --- | --- | --- |
| 0. 环境基线 | 用户切换 Tahoe 后记录系统/build、工作 EFI 和回退入口 | 外接盘可重复启动，输入可用，救援路径确认 |
| 1. 差异审计 | 对比本机 PCI/BAR、GPU IP、显存、面板和候选实现假设；审核许可证 | 有脱敏差异清单和明确的阻塞项，不写硬件寄存器 |
| 2. 可复现构建 | 固定上游提交、工具链和依赖；建立独立实验分支 | 构建步骤、产物来源、校验值和回退步骤可追踪 |
| 3. GPU 最小工作 | 验证初始化、GPUVM、命令提交及完成同步 | GPU 计算结果正确且与 CPU 预期一致，无超时/挂起 |
| 4. 内屏输出 | 验证 framebuffer、scan-out、模式设置与同步 | 多次冷启动无黑屏，实际面板参数匹配 |
| 5. Metal 与合成 | 最小 Metal 测试，应用与 WindowServer 逐项接入 | 正确渲染及真实 GPU 工作证据，不只看设备名称 |
| 6. 稳定性 | 持续负载、内存压力、重启、显示休眠/唤醒 | 测试记录可复核，失败有回退，明确未支持功能 |

## 初期不承诺的内容
- 视频硬件编解码、外接显示、背光与完整睡眠支持。
- Sonoma 回移植或所有 780M 笔记本兼容。
- 通过显卡驱动解决外接 USB 鼠标卡顿；USB/HID 问题独立跟踪。
- 固定完成时间或一定成功。

## 每次测试记录
记录日期、系统/build、代码提交、实验 EFI 版本、唯一改变的变量、复现步骤、预期/实际结果、错误与回退结果。
原始材料留本地，仅提交人工核对后的脱敏摘要。未经实机验证的补丁必须标为实验性。
